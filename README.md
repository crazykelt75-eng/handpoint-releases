# HandPoint downloads

HandPoint lets you control an Android phone by moving your hand in front of it: a cursor follows your hand, and pinches become taps, scrolls and Back. Everything runs on the phone.

**Download the latest version:** [HandPoint.apk](https://github.com/crazykelt75-eng/handpoint-releases/releases/latest/download/HandPoint.apk) (Android 11 or newer).

Install and setup steps are on the [release page](https://github.com/crazykelt75-eng/handpoint-releases/releases/latest).
